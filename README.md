# AstrBot 群友语录插件

什么？群友又爆典了？当然是截图保存让他名垂千古口牙（

截图投稿群友的逆天语录，被戳一戳或发送 `/语录` 时随机发送一张群友的黑历史。支持冷却防刷屏与「去重随机」算法，避免短期内连续刷到同一张。

## 指令一览

均需带指令前缀（默认 `/`）。

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/语录` | 全体 | 随机查看一条本群语录 |
| `/语录投稿` | 受投稿权限控制 | 投稿一张语录图片，可直接带图，或回复一条含图消息 |
| `/语录状态` | 全体 | 查看本群语录数量、投稿权限与冷却设置 |
| `/投稿权限 <0\|1\|2>` | 管理员 | 设置投稿权限：0 关闭 / 1 仅管理员 / 2 全体 |
| `/戳戳冷却 <秒>` | 管理员 | 设置戳一戳触发语录的冷却时间 |

> 投稿方式：`/语录投稿` 后跟图片；或回复一条含图消息并发送 `/语录投稿`。

## WebUI 配置项

插件支持在管理面板直接配置（`_conf_schema.json`）：

- **默认投稿权限模式**：群未单独设置时使用的投稿权限（0/1/2，默认 0）
- **默认冷却时间**：戳一戳触发的默认冷却秒数（默认 10）
- **触发语录概率**：被戳时发送语录的概率，0~1（默认 0.85，剩余概率发送随机趣味文本）
- **去重窗口**：最近被抽到的若干张会被降低重复概率（默认 8）

群级设置（通过 `/投稿权限`、`/戳戳冷却` 设置）会覆盖全局默认值。

## 数据存储

语录图片按群隔离，存放于 `data/plugin_data/quote_collocter/<群号>/` 下，符合 AstrBot 存储大文件规范，更新/重装插件不会丢失数据。

## 版本更新

### v2.0
- 重写为标准 AstrBot 插件结构：使用 `@filter.command` 注册指令、`@filter.permission_type(ADMIN)` 管理权限、`AstrBotConfig` 配置注入、`_conf_schema.json` 可视化配置。
- 数据迁移至 `data/plugin_data/quote_collocter/`，遵循官方存储规范。
- 优化随机算法：采用「打乱顺序 + 指针递增 + 去重窗口」，保证一轮内不重复、且新局开头不紧接上局末尾，队列持久化到 `order.json`。
- 新增 `/语录状态` 指令查看群状态。
- 戳一戳逻辑整理为独立监听器，冷却与状态写入群级 `settings.json`。

### v1.5
- 支持引用回复投稿、本地缓存/ API / URL 三级容错下载、主动 `/语录` 指令。

### v1.3
- 新增冷却功能，防止刷屏。

## 注意事项

- 图片投稿没有内容限制，请自行审核。
- 戳一戳与本地缓存下载仅 OneBot v11（aiocqhttp）平台支持。
